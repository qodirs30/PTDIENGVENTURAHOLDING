# PT Dieng Ventura Holdings — Website Master Prompt Package

## Purpose
This folder contains the three master prompts for generating the official investor-facing landing page.

## Prompt order
1. `01_PRODUCT_BRAND_INFORMATION_ARCHITECTURE.md`
2. `02_UI_UX_VISUAL_COMPONENT_SYSTEM.md`
3. `03_FULLSTACK_ENGINEERING_SEO_SECURITY_DEPLOYMENT.md`

## Source basis
The prompts synthesize FILE 01–FILE 07:
- Vision
- Holding Company
- Investment Proposal
- Financial Model
- Investor Pitch Deck
- Investor Valuation & Term Sheet
- Investor Data Room

## Recommended execution
Paste the prompts into the selected AI website builder in sequence.

Preferred order:
1. Prompt 01 — establish business/content architecture.
2. Prompt 02 — establish UI/UX and visual system.
3. Prompt 03 — enforce engineering, SEO, security, testing and deployment requirements.

## Asset folder
Create a sibling asset directory containing:
- approved logo;
- brand assets;
- approved Dieng/Karangsari Forest Park photography;
- favicon;
- icons;
- approved PDFs;
- approved contact details;
- approved legal copy.

Do not place confidential investor/legal documents in the public web `public/` directory.

## Data rule
Financial and legal values must come from approved source documents. Never invent revenue, EBITDA, ROI, BEP, valuation, equity percentage, permits, ownership or investor rights.
